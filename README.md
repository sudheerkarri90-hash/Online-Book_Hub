Online-Book_Hub
The Online Bookstore is a web-based platform where users can browse, search, and buy books. Built with Java Servlets, JSP, and JDBC, it offers features like user login, book catalog, shopping cart, and order management. Admins can manage inventory, while customers enjoy a simple and secure buying experience.

The system allows users to **register, log in, and manage their accounts**, ensuring personalized access and secure authentication. Customers can **browse a well-organized book catalog**, search for books by title, author, or category, view detailed book descriptions, and check availability in real time. The **shopping cart** feature enables users to add, update, or remove books before checkout, making the buying process flexible and convenient.

Once an order is placed, the platform supports **order management**, allowing customers to track their purchases and view order history. Secure database connectivity via **JDBC** ensures reliable storage and retrieval of user data, orders, and inventory information.

On the administrative side, **admins have full control over inventory management**, including adding new books, updating prices and stock levels, and removing outdated entries. This ensures that the bookstore remains up to date and well maintained.

Overall, **Online-Book_Hub** delivers a **simple, secure, and efficient online shopping experience**, combining a clean user interface with powerful backend functionality, making it suitable for both customers and administrators in a real-world e-commerce environment.
